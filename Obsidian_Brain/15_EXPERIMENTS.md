# 🧪 Experiments — Hypotheses & Tests

> Every experiment is a win: it works or it teaches ([[01_TAO]]). Linked from [[00_README]]

## Rules

1. **Written before started.** Hypothesis, budget (time + money), kill condition, review date.
2. **Capped downside.** No experiment may exceed its budget — extensions are a *new* experiment.
3. **Weekly triage** ([[04_OPERATING_SYSTEM]]): every active experiment gets promoted, continued, or killed.
4. **Results always land.** Wins → the relevant system note; lessons → [[16_LEARNING_LOG]]; data → [[13_KNOWLEDGE_BASE]].

## Template

```
## EXP-{nn} {name}
- Hypothesis: If {change}, then {measurable outcome}, because {reasoning}.
- Budget: {hours} / R{amount}
- Kill condition: {signal that ends it early}
- Review date: {YYYY-MM-DD}
- Status: ACTIVE | PROMOTED | KILLED
- Result: {filled at review}
```
