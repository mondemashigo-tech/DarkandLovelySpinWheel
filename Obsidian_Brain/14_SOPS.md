## SOP-01 Project kickoff

1. One-pager written (problem, user, smallest version, metric) → Gate 1, [[07_PROJECT_FRAMEWORK]]
2. Decision filter passed → [[11_DECISION_FRAMEWORKS]]
3. Repo created; branch conventions set
4. Agent brief written from template → [[12_PROMPT_ENGINEERING]]
5. Ship date in calendar (≤ 2 weeks out)

## SOP-02 Launch checklist

1. Quality checklist passed → [[08_CREATIVE_STANDARDS]]
2. Tested cold on a mid-range Android device
3. Analytics/metric tracking confirmed firing
4. Rollback path known (previous build tagged)
5. Announcement copy drafted and approved
6. Post-launch: 30-day review date set → Gate 4

## SOP-03 Client proposal

1. Qualify: budget, deadline, decision-maker confirmed
2. Price the outcome (rules in [[09_BUSINESS_SYSTEMS]])
3. Proposal: problem → approach → deliverables → timeline → price → 50% upfront terms
4. Send within 48h of the qualifying call; follow up on day 3

## SOP-04 Client handover

1. Deliverables checklist signed off against the proposal
2. Credentials transferred securely (never via chat)
3. One-page "how to run this" doc delivered
4. Case study notes captured → [[13_KNOWLEDGE_BASE]]
5. Testimonial requested; retainer option offered
