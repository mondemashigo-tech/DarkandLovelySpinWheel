# ⚙️ Operating System — Cadence & Rituals

> How time is structured so the work runs itself. Linked from [[00_README]]

## Daily

| Block | Ritual |
|---|---|
| Morning | Review yesterday's [[17_DAILY_LOGS]] entry → set today's 1–3 priorities |
| Deep work | Primary project only ([[07_PROJECT_FRAMEWORK]]) — no inbox, no chat |
| Admin block | Messages, follow-ups, pipeline updates ([[09_BUSINESS_SYSTEMS]]) |
| Shutdown | 3-line daily log: *done / learned / next* → [[17_DAILY_LOGS]] |

## Weekly review (non-negotiable)

1. Empty all capture points into the vault → [[06_MEMORY_SYSTEM]]
2. Update project statuses → [[07_PROJECT_FRAMEWORK]]
3. Check pipeline and money → [[09_BUSINESS_SYSTEMS]]
4. Log one lesson → [[16_LEARNING_LOG]]
5. Kill or promote one experiment → [[15_EXPERIMENTS]]

## Monthly

- Refresh the focus table in [[02_MONDE]]
- Audit automations still earning their keep → [[10_AUTOMATION]]
- Brain changelog entry → [[19_EVOLUTION]]

## Quarterly

- Re-read [[01_TAO]]; challenge any principle that has gone unused
- Set the quarter's single primary objective

## Rules

- If a ritual is skipped twice in a row, that's a signal — log it in [[16_LEARNING_LOG]] and simplify the ritual rather than forcing it.
- Anything repeated 3+ times becomes an SOP → [[14_SOPS]] or an automation → [[10_AUTOMATION]].
