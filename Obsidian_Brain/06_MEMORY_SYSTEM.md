# 🧬 Memory System — Capture → Distill → Retrieve

> How nothing gets lost. Linked from [[00_README]]

## The flow

```
Capture (anywhere) → Inbox → Daily log → Permanent notes → Retrieval
```

1. **Capture** — WhatsApp self-chat, voice notes, screenshots, quick Obsidian notes. Zero friction; no formatting.
2. **Inbox processing** — during the daily shutdown or weekly review ([[04_OPERATING_SYSTEM]]), every capture is either:
   - logged in [[17_DAILY_LOGS]],
   - filed into a numbered note (00–19), or
   - deleted. *No third pile.*
3. **Distill** — recurring themes get promoted: procedures → [[14_SOPS]], lessons → [[16_LEARNING_LOG]], facts → [[13_KNOWLEDGE_BASE]], links → [[18_REFERENCE_LIBRARY]].
4. **Retrieve** — search + wiki-links. Every note must be reachable from [[00_README]] within two hops.

## Note conventions

- **Frontmatter**: `tags`, `created`, `status` (`active` / `evergreen` / `archived`)
- **Links over folders** — the numbered backbone is the only "structure"
- **One idea per note** when a topic outgrows its section
- Titles are nouns, logs are dated `YYYY-MM-DD`

## Status meanings

| Status | Meaning |
|---|---|
| `active` | Being worked/updated frequently |
| `evergreen` | Stable reference; reviewed on cadence |
| `archived` | Kept for history; excluded from reviews |

## Health checks (monthly)

- Inbox at zero?
- Any note not linked from anywhere? Fix or delete.
- Anything I searched for twice and couldn't find? Restructure — log it in [[19_EVOLUTION]].
